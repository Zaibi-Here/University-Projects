# UrbanHarvest - Online Grocery Store 🛒🥬

UrbanHarvest is a simple yet complete online grocery store that allows users to buy fresh grocery items from the comfort of their homes. This project includes a user-friendly frontend and a powerful admin backend developed using PHP and MySQL.

## 📁 Project Structure

- Home Page
- Shop Page
- About Us Page
- Contact Us Page
- My Orders Page
- Admin Panel (PHPMyAdmin + MySQL)

## 🧰 Technologies Used

- HTML, CSS, JavaScript
- PHP (Backend)
- MySQL (Database)
- phpMyAdmin (Database Management)

## 🗂️ Database Details

- Database Name: `urban`
- Main Tables: `users`, `products`, `cart`, `orders`, `admin`

## ⚙️ How to Setup the Project

### 1. Clone or Download the Project
```
git clone https://github.com/Zaibi-Here/University-Projects.git
```

### 2. Move Project to Local Server Directory
If you're using **XAMPP**, move the project folder to:
```
C:/xampp/htdocs/
```

### 3. Start Apache and MySQL
- Open **XAMPP Control Panel**
- Start **Apache** and **MySQL**

### 4. Import Database
- Open `http://localhost/phpmyadmin`
- Click on **Import**
- Select the `urban.sql` file included in the project folder
- Click **Go** to import

### 5. Run the Project
Open your browser and go to:
```
http://localhost/urban/
```

## 👨‍💼 Admin Panel
- URL: `http://localhost/urban/index.php`
- Login credentials can be found or added in the `admin` table of the database

## 📦 Features

- Browse grocery items and add to cart
- Checkout system with order confirmation
- Orders listed under "My Orders" page
- Admin can manage products and view orders
